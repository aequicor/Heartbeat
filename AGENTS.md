# AGENTS.md

Инструкции для ИИ-агентов (Claude Code, Codex, Junie и др.) лежат в [CLAUDE.md](CLAUDE.md) — это единый источник правды.
Дополнительно: правила по путям — `.claude/rules/`, процедуры — `.claude/skills/*/SKILL.md`, архитектура — `docs/ai/`.

## Обязательный порядок работы для Codex

- Перед изменениями прочитай `CLAUDE.md` и подходящие по путям файлы `.claude/rules/`.
  Не рассчитывай на их автоматическую загрузку: открывай применимые правила и процедуры явно.
- При планировании коммитов и PR прочитай [политику коммитов](docs/ai/commit-policy.md).
- Перед завершением задачи выполни применимые проверки из [verify](.claude/skills/verify/SKILL.md).

## PR и коммиты

- **Один PR содержит законченную фичу**, коммиты внутри него — отдельные логические шаги.
  Каждый коммит оставляет проект собираемым; тесты изменённого поведения идут вместе с реализацией.
- **Не более 25 000 токенов полного diff на коммит.** Свыше 20 000 токенов или 20 файлов —
  предупреждение. 700–1000 добавленных и удалённых строк суммарно — ориентир, а не блокер.
  Общего лимита размера PR нет.
- Перед каждым коммитом проверь подготовленные изменения:
  `python scripts/check_commit_size.py --staged`.
- Перед созданием или обновлением PR проверь каждый коммит ветки:
  `python scripts/check_commit_size.py --base <base-ref> --head HEAD`.
  `<base-ref>` — актуальная целевая ветка PR, например `origin/master`.
- Превышение 25 000 токенов требует разделения логического шага на собираемые коммиты.
  Не заменяй подсчёт токенов оценкой по строкам; ошибка инструмента не означает успешную проверку.

Методика подсчёта, установка зависимостей и особенности merge/binary-файлов описаны
в [политике коммитов](docs/ai/commit-policy.md); краткие правила выше должны ей соответствовать.
