Прочитай и выполни [общую процедуру ui-prototype](../../../.claude/skills/ui-prototype/SKILL.md).
Относительные ссылки в ней разрешай от каталога исходного файла; команды выполняй из корня репозитория.
Вместо `$ARGUMENTS` используй фичу и предмет проектирования из задачи.

При работающем MCP pen.dev все операции с макетом выполняй через него; computer-use для pen.dev не используй, включая сохранение и проверку вкладки. Если операции нет в MCP, сообщи об ограничении, не переходя к computer-use. Если MCP недоступен текущему движку, используй запасной способ из общей процедуры. Не перезаписывай несохранённые пользовательские правки.

Комментарии на макете оформляй по разделу «Правила добавления комментариев» общей процедуры: номерной бейдж на компоненте и соответствующая sticky-note под экраном. Экраны и их варианты должны оставаться отсоединёнными и редактируемыми.
