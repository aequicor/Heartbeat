Прочитай и выполни [общую процедуру open-pr](../../../.claude/skills/open-pr/SKILL.md).
Относительные ссылки в ней разрешай от каталога исходного файла; команды выполняй из корня репозитория.
`$ARGUMENTS` в процедуре — текст после `$open-pr` в запросе пользователя; `/open-pr` и `/continue-pr` в ней
означают `$open-pr` и `$continue-pr` ([навык continue-pr](../continue-pr/SKILL.md)).
Проверки выполняй по навыку [verify](../verify/SKILL.md).

Для планирования UI добавляй в раздел «Дизайн» PR ссылки на сохранённые `.pen` и доступные превью экранов по разделу «Макеты под рукой при планировании» общей процедуры. Материалы должны открываться с другой машины; при работающем MCP pen.dev computer-use не используется.
