# ModelChecks: предупреждение и подробности

Перенос утверждённых Desktop-состояний `check-failed` / `check-details` макета `ddd1ae48135a6ae9719249b87c4b60d47b38e938`.
Рендеры текущей реализации на ширинах 420 и 1280, светлая и тёмная тема. Только синтетические данные тестового профиля.

Генератор: `ConnectionsSnapshotTest` в `features/ai-engine/connections/impl/src/jvmTest`.
Проверены UI-тестами: просмотр без запросов, явный повтор, запрет повторного запуска во время pending, Esc и возврат фокуса,
удаление строки успеха во время ожидающего возврата фокуса. Ответы выводятся обычным текстом без активных ссылок.

Диалог использует реальные фиксированные пробы вместо сокращённого иллюстративного текста макета, поэтому тело выше и прокручивается при необходимости.
Основная панель на заднем плане ещё переносится; эти кадры не подтверждают четыре вкладки или полный редизайн.
Компактный рендер проверяет поведение UI при сужении и не заменяет согласование мобильного прототипа.
