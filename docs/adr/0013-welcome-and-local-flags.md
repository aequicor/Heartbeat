# ADR-0013: Welcome и локальные настройки флагов

Статус: принято. Дата: 2026-09-27.

## Контекст

Основное приложение показывало шаблон Compose. Требуется светлое кинематографичное
приветствие, переход в заготовку AI-studio и рабочие настройки флагов без авторизации.

## Решение

- Три фичи `welcome`, `ai-studio`, `toggles-panel`, каждая с контрактом машины в `api`
  и реализацией в `impl`. Используются существующие convention-плагины KMP/Compose/Metro.
- Внутри `impl`: `domain` — эффекты и порты без DI/IO, `data` — адаптеры флагов,
  `presentation` — сторы, UI-модели и навигационные компоненты, `ui` — Compose и
  адаптеры рендеринга. UI не получает интенты машины и определения флагов; Metro-сборка остаётся в `di`.
- Маршруты зарегистрированы в AppScope; граф каждой записи удерживается через
  `retainedGraph`. Только `platform-main:di-bundle` подключает реализации.
- `core:mvi` создаёт FlowMVI-сторы с инжектируемым dispatcher, логированием имён типов
  вместо содержимого и обязательным преобразованием ошибки в состояние экрана.
- Welcome проигрывает конечную сцену длительностью 6 секунд. Пропуск, reduced motion
  и `welcome.cinematic_intro=false` открывают финальные действия сразу. Готовая
  функциональность включена по умолчанию. Изменение флага влияет на следующее интро.
- Новый запуск без saved state начинает вступление; восстановление ОС продолжает
  сессию с готового экрана. Возврат из дочернего экрана не повторяет вступление.
- Запрос навигации хранится в состоянии машины до подтверждения компонентом.
  `SingleTop` предотвращает дубли при пересоздании компонента.
- Панель флагов доступна пользователю в debug и release согласно продуктовому
  требованию. Она управляет только локальными переопределениями текущего устройства;
  удалённого администрирования и сетевых операций нет. Доступ к панели не закрывается флагом.
- Наблюдение `FeatureToggleControl` живёт весь период Active, включая запись через
  `stay`. Ошибка записи не стирает наблюдаемые значения; повтор только явный.

## Последствия

Цвета и размеры welcome вынесены в дизайн-систему отдельно от компактных рабочих
экранов. AI-studio пока показывает честное пустое состояние. Существующие платформенные
каталоги не переносятся; Android сохраняет app-граф в Application, iOS — в AppDelegate,
Desktop связывает root lifecycle с окном. iOS-сборка требует проверки на macOS.
