# ADR-0004: Mission Design System и отдельная UIKit Sandbox

- Статус: принято
- Дата: 2026-09-26
- Затрагивает: `design-system:*`, `platform-main:uikit-sandbox:*`
- Визуальная палитра и основной стиль заменены [ADR-0005](0005-pastel-neumorphism.md); архитектура сохраняется.

## Контекст

Студии нужен общий визуальный язык на Android, iOS, Windows и macOS. Чат должен показывать
постепенно обновляемые ответы и разные типы сообщений, не связывая UI с конкретным агентом
или транспортом. Компоненты и примитивы размещения должны развиваться независимо.

## Решение

Дизайн-система состоит из семи модулей:

- `tokens`: исходная палитра Mission, семантические цвета, типографика, размеры,
  отступы, формы, elevation и параметры движения;
- `adaptive`: Material на мобильных устройствах, Fluent и macOS UI на JVM;
- `theme`: CompositionLocal-провайдеры и единая `HbTheme`;
- `resources`: Compose Resources, строковые ключи и локаль композиции;
- `layouts`: Row, Column, lazy list и адаптивное размещение;
- `components`: stateless-компоненты, сообщения, transcript и composer;
- `catalog`: интерактивные примеры и локальная демонстрация потока.

Платформенные библиотеки доступны только через `adaptive`. JVM выбирает кит по ОС,
а каталог позволяет явно переключить его для сравнения. Desktop-зависимости не попадают
в Android/iOS. Низкоуровневые карточки, badges и сообщения рисуются Compose Foundation
с токенами Mission; системные кнопки и поля используют адаптеры соответствующих китов.

Desktop-приложение и UI-тесты каталога запускаются на JDK 21: опубликованный
`compose-macos-ui:1.1.0` содержит class files версии 65. Общая KMP-конвенция,
Android и core остаются на JVM 17. Нативный установщик поставляет совместимый runtime.

Производные цвета вычисляются из палитры: текст второго уровня — 72% основного текста
на поверхности, границы элементов управления — 55%, декоративные границы — 12%,
приподнятая поверхность — 4%, цветные контейнеры — 12% акцента на поверхности.
Для текста на насыщенных акцентах выбирается чёрный или белый с наибольшим контрастом.
Исходные цвета не заменяются ради контраста. Пары текста проверяются тестами на 4.5:1,
границы интерактивных элементов — на 3:1.

Для состояний нативной кнопки macOS учтены наложения библиотеки: 10% белого при hover
и 8% чёрного при нажатии. Цвет её текста пересчитывается по фактическому фону,
поскольку кит использует белый текст независимо от `onAccent`. Fluent получает
явные Mission-цвета для normal/hover/pressed, вместо автоматически сгенерированных
китом оттенков. Эти пары также покрыты тестами контраста.

Строки EN/RU хранятся в XML Compose Resources. `HbResources` задаёт язык в области
композиции, `hbString` выбирает соответствующий ресурс. Это позволяет иметь окна и
превью на разных языках без изменения глобальных `Locale`/`NSUserDefaults`.
Схема явных ключей документирована в `design-system/resources/README.md`.

Модель чата содержит устойчивый ID и настройки представления. UI получает неизменяемый
список сообщений и callbacks. Сетевые потоки, история и машины фич сюда не входят.
Автопрокрутка учитывает позицию чтения: просмотр старых сообщений не должен прерываться
поступлением следующего фрагмента ответа.

Sandbox — отдельное приложение с независимыми Desktop/Android/iOS точками входа.
Каталог не подключён к приложению студии и не регистрирует бизнес-фичи. Его локальные
настройки и демонстрационная генерация живут в памяти; они не требуют нового слоя
DataStore, Koog, Metro-графа или пользовательских feature toggles. Это ограниченное
исключение для инструмента разработки, а не шаблон реализации бизнес-фичи.

## Альтернативы

| Вариант | Причина отказа |
|---|---|
| Один модуль для всей ДС | Смешивает токены, размещение, ресурсы и готовые элементы |
| Отдельная копия UI для каждой платформы | Разводит поведение чата и визуальные токены |
| Встроить каталог в главное приложение | Связывает инструмент разработки с бизнес-графом и поставкой студии |
| Глобально менять системную локаль | Создаёт побочные эффекты между окнами и приложением-хостом |

## Последствия

Новые фичи используют `Hb*` и `HbTheme`; реализации китов остаются внутри ДС.
Для производственного чата потребуется отдельная фича api/impl по ADR-0001,
с FlowMVI/KStateMachine и подключением Koog. iOS и macOS проверяются на macOS;
Windows-проверки общего кода не заменяют сборку в Xcode.
