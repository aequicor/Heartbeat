Проведи приёмку фичи #{{issue}} (PR: {{pr}}) в продуктовом цикле Heartbeat. Если PR не указан — возьми его из доски/эпика; если PR нет, приёмку не начинай.

1. Загрузи навык testing_acceptance (harness_skill_load product_lifecycle/testing_acceptance).
2. Пройди acceptance criteria из функц. требований фичи (под-issue артефакт эпика #{{issue}}) пункт за пунктом; фиксируй результат каждого пункта.
3. Прогони verify (сборка, тесты, detekt) на head PR {{pr}}; чужие ОС — module-build.yml по правилам AGENTS.md.
4. Оформи отчёт в под-issue «Приёмка: <тема>» (метки type:artifact, source:agent; sub-issue эпика #{{issue}}): чек-лист с результатами, отклонения, замечания, ссылки на прогоны.
5. Пригласи пользователя подтвердить приёмку (кратко, со ссылкой на отчёт). Замечания — в дефекты (defect_flow) или правки в PR; приёмку подтверждает человек.
6. Подтверждено → следующий шаг: подготовка релиза (навык release_prep, кнопка «Релиз: подготовка»); метку stage:released вешать только после публикации релиза.
