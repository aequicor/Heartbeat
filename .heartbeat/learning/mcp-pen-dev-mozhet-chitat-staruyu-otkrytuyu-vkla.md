При проверке сохранённого .pen учитывай, что MCP Get с filePath ранее открытого документа может вернуть старое состояние вкладки после замены файла на диске. Если результат расходится с сохранённым файлом, проверь хэши и прочитай через MCP побайтовую копию в новом временном пути, сохранив относительную структуру импортируемой библиотеки. Не перезаписывай оригинал данными старой вкладки и не считай такой Get доказательством содержимого диска.
