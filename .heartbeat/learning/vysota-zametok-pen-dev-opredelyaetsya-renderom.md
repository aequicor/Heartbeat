При размещении note в pen.dev проверяй фактическую высоту через MCP Get bounds и PNG Export: заданная height ниже минимума может игнорироваться, а fontFamily/fontSize для note не применяться. Разводи заметки и группы по фактическим размерам, затем проверяй отсутствие перекрытий; не считай заданную height доказательством компактного рендера.
