В computer-use E2E не делай вывод о неверном API-ключе только по 401: быстрый window_type может потерять символы в Compose-поле. При подозрении повтори ввод посимвольно, дожидаясь свежего window_screenshot между символами; для секретов сравнивай только длину и отпечаток в собственном изолированном тестовом хранилище, не выводи значения.
