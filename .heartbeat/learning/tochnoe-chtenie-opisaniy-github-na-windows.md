Для точной сверки Unicode-описаний GitHub не полагайся на текст stdout hosted run_command: он может содержать повреждённые символы на границах вывода. Получай gh JSON через Python subprocess с capture_output=True, декодируй stdout как UTF-8 и сравнивай внутри скрипта; наружу выводи краткий ASCII-результат. При сравнении Markdown нормализуй CRLF/LF; при записи UTF-8 явно задавай newline='\n'.
