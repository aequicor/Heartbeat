Наблюдение для прежнего Windows-хоста Heartbeat: автоматическая проверка отклоняла конкретные вызовы `git push` и сетевые записи через shell; публикацию выполнял пользователь вручную, а описание PR обновлялось доступными инструментами GitHub. Это не общее правило Heartbeat и не запрет для других хостов. На текущем хосте сначала проверь доступные инструменты, авторизацию и фактический результат операции. При отказе следуй его причине; ручной push нужен только при подтверждённой недоступности разрешённой публикации.
