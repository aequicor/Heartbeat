В чатах Heartbeat `git push` (и любые network-write команды, включая `gh pr create` через shell) отклоняется автоматической проверкой безопасности хоста с текстом вида «The safety review refuses git push (network write)». Механизма одобрения сетевой записи из чата нет, ретраить бесполезно. Рабочий флоу публикации: попросить пользователя выполнить `git push -u origin <branch>` в своём терминале, затем создать draft PR хостовым инструментом github_pr_create (учётные данные хоста, эта операция разрешена) и обновлять описание через github_pr_update. Каждый новый готовый шаг коммита требует повторного ручного push пользователем.
