# Heartbeat для Chromium-браузеров

Расширение (Manifest V3) для Google Chrome, Microsoft Edge, Brave, Chromium и Vivaldi — тонкая прослойка между
браузером и desktop-приложением Heartbeat:

- **чат Heartbeat в боковой панели браузера** — чаты студии профиля, отправка сообщений, потоковые ответы,
  «Стоп», ответы на запросы разрешений, вложение страницы и выделения;
- **управление браузером агентами Heartbeat** — инструменты `ex_control_*`: агент работает в своих вкладках
  (группа «Heartbeat») и во вкладках пользователя только после явного разрешения.

Движки, профильные данные и выполнение команд живут в приложении (`features/chromium-bridge`, `features/browser`), Compose/Wasm-панель использует общие со студией экран, модели и UI анкет/чек-листов; service worker передаёт
сообщения и исполняет команды браузера.

## Установка (разработка)

1. Соберите панель из корня репозитория: `./gradlew :chromium-plugin:panel:syncChromiumPanel`.
   Gradle создаёт `chromium-plugin/app/` (Wasm, JS и ресурсы); каталог игнорируется git.
   Шрифты Noto скачиваются с закреплённых версий и проверкой SHA-256; повторная сборка использует кэш.
2. Запустите Heartbeat на Windows или macOS и включите тогл `chromium_bridge.enabled`
   (для чатов профиля нужен также `ai_studio.engine_runtime`).
3. Heartbeat → «Настройки» → «Браузер Chrome» → «Зарегистрировать» для нужного браузера. Регистрация пишет
   манифест хоста Native Messaging `io.aequicor.heartbeat` (macOS — каталог `NativeMessagingHosts` браузера,
   Windows — ключ реестра `HKCU\Software\<vendor>\NativeMessagingHosts`).
4. Откройте `chrome://extensions` (`edge://extensions`, `brave://extensions`), включите режим разработчика,
   «Загрузить распакованное расширение» и выберите эту папку.
5. Идентификатор расширения должен быть `dngnkjkjppehmiaebojfebjcfkcpdjki` — его закрепляет публичный ключ
   `key` в `manifest.json`, и только его допускает манифест хоста.

Приватный ключ в репозиторий не входит (`*.pem` игнорируется): для распакованного расширения он не нужен.

## Панель студии

Панель показывает тот же адаптивный экран: выбор модели и effort, доверие, проекты и чаты, worktree,
организмы, анкеты и чек-листы. Выбор локальных файлов/папок, открытие/экспорт вложений и split в браузере
недоступны. Кнопка страницы прикрепляет Markdown текущей вкладки; выделение из контекстного меню ждёт
явного прикрепления. Если чат сменился во время захвата, готовая страница остаётся для ручного выбора.

После потери связи старый экран доступен для чтения; ввод ждёт нового снимка. При пересоздании вида старые
команды не повторяются, текст черновика можно восстановить отдельной кнопкой. Слишком большой экран
предлагает новый вид. В выводе инструментов передаётся хвост до 256 КиБ с отметкой усечения.

При упаковке desktop `collectAppResources` сначала собирает панель и включает `app/` в папку расширения.
Для разработки после изменений повторите сборку и перезагрузите расширение на странице управления.

## Как это устроено

```
service worker ──connectNative──▶ хост (лаунчер Heartbeat в режиме --heartbeat-chromium-host)
                                    │ те же кадры: 4 байта длины (LE) + UTF-8 JSON
                                    ▼
                         Unix domain socket приложения ──▶ features:chromium-bridge
```

- Хост запускает Chrome; хост сообщает `{"kind":"host","state":"waiting"|"connected"}` — запущен ли Heartbeat.
- После `connected` расширение отправляет `hello` (версия протокола, версия расширения, браузер, возможности);
  до успешного `hello` приложение отвечает на всё `not_ready`.
- Сообщения: `req` / `res` / `evt` в обе стороны; кадры приложения больше 1 MB приходят частями `chunk`
  (base64 срезов UTF-8 байтов) и собираются `src/shared/chunks.js`.
- Пока порт открыт, service worker не засыпает; при закрытии порт переоткрывается с паузой (1 с → 1 мин),
  а периодический `chrome.alarms` будит worker для следующей попытки.

| Файл | Назначение |
|---|---|
| `src/shared/protocol.js` | Версия протокола, имя хоста, коды ошибок, `BridgeError` |
| `src/shared/chunks.js` | Сборка `chunk`-кадров |
| `src/background/native-link.js` | Порт Native Messaging: статусы, `hello`, запросы и ответы, переподключение |
| `src/background/service-worker.js` | Сборка расширения |
| `src/background/panel-hub.js` | Ретрансляция `studio.watch` / `studio.intent` / `studio.attachPage` |
| `src/sidepanel/panel-host.js` | Порт, захват страницы и выделения для Wasm |
| `panel/` | Compose-оболочка, зеркальный стор и общий экран студии |

## Проверка

```bash
node --test chromium-plugin/tests/
./gradlew :chromium-plugin:panel:jvmTest :chromium-plugin:panel:syncChromiumPanel
```

Тесты — встроенный раннер Node (≥ 22.12), без npm-зависимостей; API `chrome.*` подменяются фейками
из `tests/fakes/chrome.js`. Код проверяется в редакторе через `// @ts-check` и `jsconfig.json`.
