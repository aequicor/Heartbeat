# Доверенные публичные ключи Ed25519, которыми подписаны записи лаунчера в слотах.
# Формат: по одному ключу в строке — X.509 SubjectPublicKeyInfo в Base64; строки с # и пустые пропускаются.
# Ключей не больше четырёх: основной (секрет CI) и запасной (хранится вне CI).
# Без ключей ни один слот не проходит проверку, и запускается встроенный лаунчер: селектор не доверяет по умолчанию.
# Файл заполняет владелец ключей перед выпуском; ключ тестового flavor в release-сборку попасть не должен.
