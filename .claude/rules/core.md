# Модули `core/*`

- `core` не зависит от `features/*` и `design-system/*`. Циклы между `core`-модулями запрещены (`logging` ← `common` ← остальные).
- Каждый core-модуль, через который проходят действия/данные, **обязан** предоставлять логирование централизованно: адаптер логгера для библиотеки или логирующую обёртку. Фичи не должны вручную логировать то, что уже проходит через core.
- Публичный API — стабильный и узкий, с KDoc. Реализация — `internal`, отдаётся через Metro `@ContributesBinding(AppScope::class)`.
- Платформенные различия — `expect/actual` только для фабрик (драйвер БД, путь DataStore, Ktor engine, платформенный Antilog). Остальное — `commonMain`.
- Секреты (API-ключи LLM) — не в коде и не в `DataStore` в открытом виде: через интерфейс `SecretStore` (Keystore/Keychain/DPAPI — реализация per-platform).
- Изменение публичного API core-модуля — прогон `./gradlew allTests` для всех зависимых модулей, и обнови соответствующий скилл в `.claude/skills/`, если меняются примеры.
