# Локализация компонентов

Все тексты хранятся в XML Compose Multiplatform Resources. `HbResources(locale)` задаёт язык отдельного дерева композиции, `hbString(HbString.Send)` читает строку. English и Russian имеют явные ключи `en_*` и `ru_*`; каждый ключ обязан иметь обе непустые строки (проверяется тестом).

На момент реализации [официальная документация](https://kotlinlang.org/docs/multiplatform/compose-resource-environment.html) предлагает менять глобальные настройки Locale / NSUserDefaults: общего публичного API override ещё нет. Явные пары ресурсов позволяют менять язык мгновенно, независимо в разных окнах и превью, без записи системных настроек и без пересоздания состояния чата. Это намеренная альтернатива платформенным глобальным workaround. Переводы не дублируются в Kotlin.
