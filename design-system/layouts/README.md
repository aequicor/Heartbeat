# Layout-примитивы Heartbeat

Модуль `design-system:layouts` отдельно от виджетов предоставляет:

- `HbColumn` / `HbRow` — стандартные Compose scope и интервалы из токенов.
- `HbFlowRow` — переносимые по строкам группы контролов и меток.
- `HbLazyColumn` / `HbLazyRow` — виртуализация, внешний `LazyListState`, направление, padding и нормализованный scrollbar.
- `Modifier.hbHorizontalScroll` / `hbVerticalScroll` — обычная прокрутка с auto-hide scrollbar.
- `Modifier.hbScrollbars` — overlay-полоса для существующего `ScrollState` или `LazyListState`, без второго владельца прокрутки.
- `LazyListScope.hbStickyHeader` — закрепляемые секции с устойчивым ключом и content type.
- `HbAdaptivePane` — боковая навигация на широком экране и верхняя область на компактном; `compactSidebar` позволяет заменить вертикальное меню горизонтальными вкладками.

Layout-примитивы не содержат продуктовых действий, текста, сетевого или агентного состояния. Их breakpoint, интервалы и ширина панели определяются `HbTheme`.

Полоса скрыта в покое; появляется при прокрутке и наведении на её область, поддерживает
перетаскивание и переход по track. Не занимает дополнительное место. Для lazy-списков
размер thumb не зависит от высот появляющихся строк: используется фиксированный масштаб
логических элементов. Положение учитывает дробный прогресс внутри видимых элементов и
границы viewport. См. [ADR-0012](../../docs/adr/0012-scrollbars.md).

Для внешней полосы (например, `HbStickyHeaderHost`) у внутреннего lazy layout укажите
`showScrollbar = false`. Обёртки прокрутки добавляйте до модификаторов внутреннего
содержимого; полоса должна измеряться по ограниченному viewport, а не по полной ширине
или высоте его содержимого.
