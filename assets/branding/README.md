# Heartbeat — фирменные материалы

Светящаяся линия ЭКГ на мягкой сине-фиолетовой шестигранной плитке. Форма и стеклянный материал
опираются на изображение-референс пользователя; главный знак — импульс сердцебиения.

| Файл | Назначение |
| --- | --- |
| `heartbeat-logo.png` | Основной PNG с прозрачностью, созданный встроенным imagegen. |
| `heartbeat-desktop-logo.png` | Стеклянная Desktop-иконка с более чётким импульсом, созданная встроенным imagegen. |
| `heartbeat-app-icon.svg` | Та же шестигранная плитка и плавный импульс, оптимизированные для 16–32px. |
| `heartbeat-macos-logo.png` | Заполненная стеклянная плитка со скруглёнными углами для macOS, созданная встроенным imagegen. |
| `heartbeat-macos-icon.png` | Готовая macOS-иконка 1024px с квадратной плиткой и одинаковыми системными отступами. |
| `heartbeat-macos-small.svg` | Заполненная macOS-плитка для малых представлений 16–32px. |
| `heartbeat-monochrome.svg` | Упрощённая векторная ЭКГ для тематической Android-иконки. |
| `heartbeat-banner.png` | Панорамный баннер README, созданный встроенным imagegen. |
| `desktop-icon-comparison.png` | Сравнение прежней и упрощённой иконок в 16–48px на светлом и тёмном фоне. |
| `macos-icon-preview.png` | Заполненная macOS-иконка в натуральных размерах 32–128px. |
| `prompts.txt` | Полные финальные промпты логотипа и баннера. |
| `desktop-prompt.txt` | Промпт уточнённой стеклянной Desktop-иконки. |
| `macos-prompt.txt` | Промпт заполненной macOS-иконки с учётом пользовательских референсов. |

## Экспорт иконок

Платформенные ресурсы экспортируются из PNG-оригинала и SVG-вариантов знака:

```bash
node scripts/generate_app_icons.cjs
```

Для этого отдельного инструмента нужны Node.js и `sharp` версии 0.35.4. Зависимость можно установить
в отдельный каталог и передать через `NODE_PATH`; она не нужна для сборки или запуска приложения.
Например, на macOS:

```bash
npm install --prefix /tmp/heartbeat-icon-tools sharp@0.35.4
NODE_PATH=/tmp/heartbeat-icon-tools/node_modules node scripts/generate_app_icons.cjs
```

Экспорт создаёт:

- Android: пять плотностей launcher/round, адаптивный foreground внутри безопасного круга 66dp и SVG-подобную монохромную ЭКГ для Android 13+.
- Windows: ICO с девятью размерами от 16 до 256px; до 32px используется векторная версия с более чёткой линией, Gradle подключает иконку к приложению и MSI.
- macOS: ICNS с обычными и Retina-представлениями до 1024px; вся скруглённая плитка заполнена стеклянной поверхностью, для малых представлений — векторная версия той же формы. Перед экспортом оба исходника приводятся к квадратной плитке 824×824px на полотне 1024×1024px с отступами 100px, чтобы все размеры совпадали по масштабу и центру.
- iOS: три непрозрачных PNG 1024px — обычный, тёмный и тонированный; скругление выполняет система.
- Desktop: PNG для окна и Dock, включая запуск из исходников.

macOS получает отдельный заполненный вариант также при запуске из исходников; Windows использует шестигранную плитку.

В представлении 16px линия имеет толщину 1px, в 32px — 2px. Шестигранный силуэт и плавная ЭКГ
сохраняют характер основной версии; небольшие представления используют чистые края без ореола.
Крупные и Retina-представления сохраняют стеклянный материал.

Баннер сохраняется отдельно; экспорт иконок его не меняет.
