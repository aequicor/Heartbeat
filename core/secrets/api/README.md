# core:secrets:api

Профильное защищённое хранилище персональных данных, токенов и API-ключей.
Получайте `SecretStore` из профильного Metro-графа. При переключении профиля старый экземпляр закрывается,
а данные и ссылки сохраняются. Новый экземпляр того же профиля видит прежние записи.

```kotlin
val key = SecretKey("credential-uuid")
val consumer = SecretUsage("engine", "engine-uuid", "api-key")
Secret(inputChars).use { secrets.write(key, it) }
inputChars.fill('\u0000')
secrets.bind(consumer, key)

secrets.readFor(consumer)?.use { secret ->
    secret.reveal { chars -> /* передать в транспорт, не логировать и не сохранять */ }
}
```

- `write(key, value)` создаёт/заменяет единственное значение; ссылки не меняются.
- `bind(usage, key)` атомарно назначает/меняет ссылку. `bind(usage, null)` освобождает слот.
- `readFor(usage)` разрешает ссылку в актуальное значение. Потребитель хранит идентификатор слота, а не копию ключа.
- `remove(key)` возвращает `Removed`, `Missing` или `InUse(usages)`. В последнем случае удаление запрещено.
  UI разрешает `type/id/slot` в названия движков/полей у владельцев этих объектов.
- `keys()` и `usages(key)` не раскрывают значения.

Идентификаторы технические, без email, имён и токенов. Пространство профиля добавляет модуль:
передавать ProfileId в каждый вызов и собирать пути не нужно.

Удаление движка должно освобождать его ссылки после удаления конфигурации. Перед созданием конфигурации
ссылка регистрируется; при неудаче создания её следует освободить. Такая последовательность при сбое
может оставить лишнюю блокировку удаления, но не позволит удалить ключ живого потребителя.
Для смены ключа потребитель использует один постоянный слот и `bind`, затем читает через `readFor`.

`Secret` копирует входной CharArray, скрывает `toString`, очищает временную копию после `reveal`
и свой буфер после `close`. Не сохраняйте массив из callback. Строки, созданные транспортом или сериализатором,
невозможно гарантированно стереть из памяти JVM/Native.

Ротация действует на последующие чтения; уже переданный транспортному клиенту/процессу ключ не меняется.
Уведомления о перезапуске движков и пользовательский экран относятся к будущему `core:ai`/фиче подключений.
