# Старт приложения

`welcome`, `ai-studio`, `toggles-panel` подключены через `platform-main:di-bundle` как
маршруты AppScope, доступные без авторизации. Решения по интро, восстановлению и
release-доступу к настройкам зафиксированы в [ADR-0013](../docs/adr/0013-welcome-and-local-flags.md).

Каждая фича содержит `api` с контрактом машины и публичным маршрутом. В `impl`:

- `domain` — сценарии эффектов и интерфейсы доступа к данным; без Metro и UI;
- `data` — адаптеры существующего сервиса флагов, который сохраняет значения в DataStore;
- `presentation` — FlowMVI-модели, преобразование состояния и событий, Decompose-навигация;
- `ui` — Compose-экраны и адаптеры `ComposableComponent`;
- `di` — сборка графа и удержание скоупа; `di/scope` — маркеры времени жизни.

Слой добавляется, когда у него есть ответственность. Студия пока не имеет доступа
к AI или собственных данных: это экран «Студия готовится к запуску» с возвратом.

Все строки экранов доступны на русском и английском через Compose Resources.
Снимки JVM UI-тестов welcome находятся в `welcome/impl/build/reports/welcome`.
